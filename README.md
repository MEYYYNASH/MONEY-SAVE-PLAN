# 🎯 MY MONEY - Saving Plans & Expense Income Tracker

A modern, glassmorphic personal finance web application for tracking daily income, expenses, monthly budgets, and automatic financial saving plan metrics.

---

## 🌟 Key Features

- 🎯 **Saving Plans (ផែនការសន្សំប្រាក់)**: Create savings goals (e.g., New Phone, Car, Emergency Fund) with automatic calculations for:
  - Remaining target amount
  - Progress percentage % bar
  - Target completion date countdown
  - Required daily (`សន្សំ/ថ្ងៃ`), weekly (`សន្សំ/សប្ដាហ៍`), and monthly (`សន្សំ/ខែ`) savings targets
- 📜 **Savings Deposit History**: Deposit money into any active plan with payment source tracking (ABA Bank, Wing, ACLEDA, Cash) and history log filtering.
- ✦ **MY MONEY AI Assistant**: Smart financial assistant that analyzes monthly income vs expenses vs active savings goals to offer real-time financial health advice (`✅ ស្ថានភាពល្អប្រសើរ` vs `⚠️ ការព្រមានហិរញ្ញវត្ថុ`).
- 💵 **Fixed Currency Conversion**: Fixed exchange rate ($1 = 4,000 ៛) with seamless toggle between USD ($) and Khmer Riel (៛).
- 📅 **Day-by-Day Transaction Breakdown**: Categorized daily transaction logs with Khmer formatted dates and daily totals.
- 🎨 **Glassmorphism Design Tokens**: Dark mode aesthetic featuring neon cyan (`#00e5ff`) accents, emerald green for income, and rose red for expenses.
- 🔐 **Authentication System UI**: Professional Login & Sign Up modal views with show/hide password toggles, Google/Telegram social buttons, and System Coming Soon notifications.
- 📱 **Mobile Bottom Navigation & "More" Sheet**: Clean 4-primary item mobile bar with slide-up glass menu for quick access to AI Assistant and Settings.

---

## 🚀 Getting Started

1. Clone or download the repository:
   ```bash
   git clone https://github.com/MEYYYNASH/MONEY-SAVE-PLAN.git
   ```
2. Open `index.html` in any web browser.
3. No server setup or build step required! All data persists locally in `localStorage`.
